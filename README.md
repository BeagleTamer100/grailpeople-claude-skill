# GrailPeople Shopping — Claude plugin

Turns Claude into a beauty shopping advisor backed by [GrailPeople](https://grailpeople.com):
7,000+ skincare, makeup, and hair products, each reviewed by real YouTube creators —
dermatologists, estheticians, and makeup artists — with direct quotes, video timestamps, and
creator credentials.

The plugin bundles two things that work better together:

- **The GrailPeople connector** (`https://grailpeople.com/api/mcp`) — five read-only tools for
  searching products and pulling creator evidence. No account or API key.
- **A skill** that teaches Claude how to use them: which tool answers which question, how to
  decompose a query into filters, how to cite a creator, and how to report a rating accurately.

The connector alone gets you the data. The plugin gets you the data plus the judgment about how to
use it.

## Install

```
/plugin install grailpeople-shopping
```

See [Claude Code plugins](https://code.claude.com/docs/en/discover-plugins) for other install
paths.

## Use it

Ask naturally — the skill activates on any beauty, skincare, makeup, or hair shopping question:

- "Best vitamin C serum according to dermatologists?"
- "Is CeraVe actually good or just overhyped?"
- "Show me what Hyram recommends for oily skin."
- "What are the best K-beauty moisturizers for sensitive skin?"

Or invoke the command directly:

```
/grailpeople Beauty of Joseon Relief Sun
```

## Tools the connector exposes

All five are read-only.

| Tool | What it answers |
|---|---|
| `search_products` | "Best X for Y", product discovery |
| `get_product_evidence` | "Is this specific product worth it?" |
| `get_brand_intel` | "Is this brand good, or overhyped?" |
| `get_creator_picks` | "What does this creator recommend?" |
| `resolve_entity` | Messy brand or creator name → exact slug/handle |

Full tool documentation: [grailpeople.com/mcp](https://grailpeople.com/mcp)

## About the ratings

`grailpeople_rating` is GrailPeople-derived, **not creator-issued**. Creators do not rate products
for GrailPeople and never see or approve these numbers — each one is generated by a language model
reading that creator's own on-camera quotes and scoring how strongly they spoke. It measures
enthusiasm expressed, not product quality. Attribute it to GrailPeople, and let the creator's own
words carry any claim about them.
